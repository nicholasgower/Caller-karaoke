This page is a placeholder served from website/static/app/, not the app itself. Build the WebAssembly app to replace it, or use the downloaded build and the hosted copy on this site.

Build it locally

Building needs Rust, the wasm32-unknown-unknown target, and Trunk: 

rustup target add wasm32-unknown-unknown
cargo install trunk --locked

Then stage the app and start the documentation server:

cd website
npm run build:app
npm start

npm start runs npm run build:app automatically, so the staging command is only needed when the app is already built or when you want to refresh it before starting.

Working on the docs only?

Run npm run start:docs to skip the browser build. That server is enough for prose and screenshots; this placeholder stays in the /play frame. To review the site at phone width, run npm run preview:ios. Add -- --path /play/ only after the WASM app has been staged.
