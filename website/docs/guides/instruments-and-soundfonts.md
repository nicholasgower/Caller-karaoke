Contra Karaoke imitates a small contra band. By default it plays a trio: a
melody instrument, a chordal accompaniment, and a second accompaniment that is a
melody instrument playing a countermelody under the tune. Playback uses sampled
instruments from a bundled subset of the Fluid R3 GM soundfont, so the app sounds
like a band on first launch without any downloads.

## Choose instruments

<Steps>
  <Step shot="prefs-instrument-melody">
    Open **Preferences** and find **Instruments**. Set **Melody** to **Fiddle**
    (default) or **Accordion**.
  </Step>
  <Step shot="prefs-instrument-accompaniment">
    Set **Accompaniment** to **Piano** (default), **Guitar**, or **Accordion**,
    then choose a **Rhythm** from the menu beside it.
  </Step>
  <Step shot="prefs-instrument-second">
    Leave **Second accompaniment** at **Accordion** for the default trio, choose
    **Fiddle** for a second fiddle, or choose **Off** for a duo.
  </Step>
  <Step shot="prefs-instrument-percussion">
    Choose **Foot taps** to keep the dance beat with a soft tap, choose
    **Drumset** for kick, snare, and hi-hat, or leave **Off** for no percussion.
    Then choose a **Percussion rhythm**; **Match style** gives foot taps a
    gallop and the drumset its basic kit.
  </Step>
</Steps>

The session's tune summary shows the selected parts above the call prompt.

## The second accompaniment

The second accompaniment is not another chord track. It is a countermelody
generated from the tune: one note per dance beat, voiced a diatonic third below
whichever melody note is sounding and snapped to a nearby chord tone. It follows
the tune's contour instead of holding a pedal, and it leaves a beat open rather
than repeating a pitch.

It stays on the same 64-beat grid, adds no new timing, and is mixed at the
**Accompaniment volume** level a little to the other side of the stereo field.
During a variation pass it rests in the same bar as the accompaniment, so a
"melody alone" bar really is alone.

## Percussion

Percussion is optional and off by default. **Foot taps** play a one-and-a
gallop by default (“one and a two and a…”), accented at the start of each beat.
**Drumset** adds a basic kick, snare, and hi-hat pattern: the hats subdivide each
beat in half for reels and in thirds for compound meters such as jigs. The
rhythm menu can change either pattern.

Percussion starts with the count-in when enabled and sits on the same 64-beat
grid. It does not change the dance timing or the calls. **Percussion volume**
controls its level; the control is available whenever percussion is on. The
percussion voices are generated by the app, so they work with the bundled
soundfont, a user-supplied font, and the built-in synth.

### Percussion rhythms

**Percussion rhythm** changes when the layer sounds, just as the accompaniment
**Rhythm** menu does. It never moves the grid or the calls.

| Rhythm | What it plays |
| --- | --- |
| Match style | Gallop foot taps, or the basic kick/snare/hat kit. |
| Basic | The style's basic pattern. |
| On the beat | An accent on each dance beat. |
| Offbeats | Accents between the dance beats. |
| Half time | One accent per bar, with a sparse kit. |
| Double time | Two accents per dance beat. |
| Shuffle | A swung long-short feel. |
| Gallop | A one-and-a triplet gallop: “one and a two and a…”. |
| Train beat | Alternating accents in steady eighth notes. |

The count-in stays one clear note per beat regardless of the selected rhythm.

## Choose an accompaniment rhythm

The **Rhythm** menu changes how the accompaniment realises the chord track. It
does not change the dance timing, the calls, or the length of the loop.

| Rhythm | What it plays |
| --- | --- |
| Match instrument | The default for the chosen voice: boom-chuck piano, strummed guitar, or sustained accordion. |
| Block chords | One bass note and chord on each dance beat. |
| Boom-chuck | Alternating bass and chord on each half beat. |
| Offbeat stabs | A held bass with short chord stabs between the beats. |
| Arpeggio | The chord tones broken into a steady arpeggio. |
| Shuffle | A swung long-short boom-chuck. |
| Strum | Alternating down and up strums on every half beat. |
| Sustained | One chord held for each harmony change. |

The accompaniment still follows the tune's quoted chords, or an inferred
progression when the ABC has none. Only its rhythm changes.

## Balance the mix

<Steps>
  <Step shot="prefs-instrument-mix">
    Adjust **Melody volume**, **Accompaniment volume**, and **Percussion
    volume**. The first two range from 0 to 1.5, with defaults of 0.75 and 0.65;
    percussion defaults to 0.5. The second accompaniment follows the
    accompaniment volume.
  </Step>
</Steps>

The session **Volume** control is a master level applied on top of this mix.

## Vary the accompaniment

<Steps>
  <Step shot="prefs-accompaniment-variations">
    In **Preferences → Text to speech**, enable **Vary the accompaniment on
    each loop**. The arranger adds small emphasis notes and the occasional bar
    with melody alone.
  </Step>
</Steps>

The variation is deterministic for a given tune and arrangement; it builds on
the selected rhythm and does not change the dance timing or the 64-beat loop
length. On a melody-alone bar the second accompaniment rests too.

## Apply the change

Instrument, rhythm, volume, and accompaniment-variation changes apply without
restarting the music. Release the control and the app re-renders the loop,
keeping the current beat. If the session is not playing, press **Play** to
render and start.
Session **Volume** changes apply immediately to the existing buffer.

## Soundfont

**Bundled: Fluid R3 GM** is the default. It is a trimmed subset of Frank Wen's
Fluid R3 General MIDI soundfont, which is MIT licensed; `CREDITS.md` records the
full notice. The subset contains only the four programs in the table below (the
melody and second-accompaniment choices share two of them), which is why it is
about 15 MB instead of the 141 MB full bank. Percussion is generated separately,
so it needs no drum preset. It needs no network access and is available on every
platform, including the browser and Android builds.

If you have a `.sf2` file on Windows or Linux, you can load it to replace the
bundled instruments for the session. The browser and Android builds cannot load
a SoundFont from a file in 0.1.0. A file you load is your responsibility,
including its license.

<Steps>
  <Step shot="prefs-sf2-loaded">
    On Windows or Linux, open **Preferences → Soundfont**, select **Load
    .sf2…**, and choose a file. The section shows the loaded name and a **Use
    bundled** button.
  </Step>
  <Step shot="prefs-sf2-removed">
    Select **Use bundled** to return to the packaged **Bundled: Fluid R3 GM**
    instruments.
  </Step>
</Steps>

The chosen instruments map to General MIDI programs in either font:

| Instrument | GM program | In the bundled subset |
| --- | --- | --- |
| Fiddle (melody) | 40 — Violin | Yes |
| Accordion (melody) | 21 — Accordion | Yes |
| Piano (accompaniment) | 0 — Acoustic Grand Piano | Yes |
| Guitar (accompaniment) | 25 — Acoustic Guitar (steel) | Yes |
| Accordion (accompaniment) | 21 — Accordion | Yes |
| Accordion (second accompaniment) | 21 — Accordion | Yes |
| Fiddle (second accompaniment) | 40 — Violin | Yes |

If a font you load does not contain one of those programs, the result depends on
the file and may be silent for that part. Choose **Use bundled** to go back to
the packaged instruments.

If neither font can be loaded, the app falls back to a small built-in
synthesizer so playback still works. That fallback is not selectable from the
interface.

## What the arranger plays

The melody follows the ABC note stream. The accompaniment follows quoted chord
symbols when the ABC has them; otherwise a simple progression is inferred from
the key and strong-beat melody notes. The selected rhythm decides which notes
sound on which part of the beat. The strum rhythm alternates a full downstroke
on the beat with a lighter upstroke off the beat, so the guitar sounds strummed
up and down rather than in one direction. The second accompaniment is derived
from the melody and that chord track, so it never needs symbols of its own. The
optional percussion follows the selected percussion rhythm, the meter, and the
dance-beat grid. Short fades and peak normalization are applied to the rendered
buffer.
